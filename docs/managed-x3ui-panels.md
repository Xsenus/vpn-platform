# Управление 3x-ui панелями

Раздел админки `3x-ui панели` закрывает roadmap-блок `11.2`: администратор может создать панель, изменить параметры подключения, проверить здоровье, запустить синхронизацию и управлять inbound-правилами.

## Что настраивается

- URL панели, логин и пароль.
- Регион, емкость, SSL verification mode и API variant.
- Автоматическое создание inbound при выдаче доступа.
- JSON-шаблон inbound по умолчанию.

## Секреты

Пароль панели хранится через `ISecretProtector` и не возвращается из API. При редактировании пустое поле пароля сохраняет текущий защищенный пароль. Чтобы заменить пароль, администратор вводит новое значение явно.

## Проверка и синхронизация

- `Проверить` запускает backend health-check панели и обновляет health status, версию и время проверки.
- `Синхронизировать` читает inbound/client состояние панели и сохраняет sync run.
- `Inbound-правила` показывают локальные правила, позволяют создать inbound и сделать его основным.
- `Клиенты, здоровье и синхронизация` показывают последние клиенты, health-check и sync run записи.

## Локальная проверка

1. Запустить backend и админку локально.
2. Войти в админку и открыть `3x-ui панели`.
3. Создать панель в sandbox/local режиме.
4. Нажать `Редактировать`, изменить SSL/API variant, емкость или шаблон inbound и сохранить.
5. Проверить, что карточка панели показывает новые значения, а пароль не раскрывается.
