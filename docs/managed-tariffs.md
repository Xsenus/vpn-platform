# Управляемые тарифы

Раздел закрывает roadmap-блоки `3.2`, `6.1`, `6.2`, часть `13.1` и `13.2`: тарифы хранятся в базе, редактируются из админки и отображаются на публичной странице покупки из расширенной модели.

## Возможности

- Администратор создает, редактирует, включает, отключает и удаляет тарифы.
- Удаление защищено: тариф с привязанными заказами или подписками нельзя удалить, его нужно скрыть.
- Для тарифа задаются название, slug, короткое и полное описание, цена, валюта, срок, устройства, лимит трафика, категория, бейдж, порядок, преимущества, сценарий выдачи и текст после оплаты.
- Публичная страница тарифов показывает активные тарифы, сортирует их по `sortOrder`, выводит преимущества, бейджи и объясняет, что произойдет после оплаты.
- Demo seed создает тарифы с преимуществами и текстами для локальной проверки.

## API

Публичный API:

- `GET /api/public/tariffs` - активные опубликованные тарифы для витрины.

Админский API:

- `GET /api/admin/tariffs` - список всех тарифов.
- `POST /api/admin/tariffs` - создать тариф.
- `PATCH /api/admin/tariffs/{id}` - обновить тариф.
- `DELETE /api/admin/tariffs/{id}` - удалить тариф, если нет связанных заказов и подписок.

## Проверка

1. Запустить API в режиме `Local`.
2. Проверить миграцию `ExtendTariffContent` и наличие новых колонок в таблице `Tariffs`.
3. Открыть `GET /api/public/tariffs` и убедиться, что у тарифов есть `features`, `badge`, `fullDescription`, `provisioningScenario` и `afterPaymentText`.
4. Войти в админку, открыть раздел `Тарифы`, создать тариф с преимуществами и текстом после оплаты.
5. Изменить цену, бейдж и активность тарифа, затем проверить публичную страницу тарифов.
6. Попробовать удалить тариф с заказом или подпиской: API должен вернуть ошибку и предложить отключить тариф.
