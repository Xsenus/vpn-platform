# История заказов и платежей в личном кабинете

## Что реализовано

Блок `4.3 Платежи и заказы` закрывает пользовательский сценарий после покупки или продления VPN. В личном кабинете пользователь видит:

- историю заказов с тарифом, суммой, каналом, провайдером, сроком оплаты и числом попыток;
- историю платежей с провайдером, суммой, статусом, датами оплаты или ошибки;
- понятные сообщения для состояний `pending`, `failed`, `succeeded` и близких backend-статусов;
- кнопку повторной оплаты для заказов, которые можно восстановить;
- копирование и скачивание безопасного JSON по заказу без `rawRequest`, `rawResponse` и `webhookPayload`;
- ссылку на оплату у платежной попытки, если провайдер вернул `confirmationUrl`.

## Поведение статусов

Сообщения формируются в `frontend/apps/cabinet/src/cabinet-payments.ts`. Там же находится список статусов, для которых разрешена повторная оплата: `PendingPayment`, `Failed`, `Expired`.

Экспорт заказа намеренно содержит только диагностические поля, которые можно показать пользователю или поддержке. Сырые ответы платежных провайдеров не попадают в скачиваемый файл, потому что в них могут быть технические данные интеграции.

## Проверки

Для блока добавлены frontend unit-тесты:

- повторная оплата доступна только для восстанавливаемых заказов;
- pending/failed/succeeded получают русские сообщения и корректный тон статуса;
- платежи группируются по заказу, последняя попытка выбирается по `createdAt`;
- экспорт заказа не содержит сырые payload платежного провайдера.
