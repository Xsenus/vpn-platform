# Управляемый FAQ

Раздел закрывает roadmap-блоки `3.3`, `7.1`, `7.2`, часть `13.1` и `13.2`: FAQ хранится в базе, редактируется из админки и отображается на публичном сайте.

## Возможности

- Администратор создает, редактирует и удаляет вопросы FAQ.
- Для вопроса задаются вопрос, ответ, категория, активность, показ на главной, показ на странице FAQ и порядок сортировки.
- Публичная страница FAQ получает данные из API, поддерживает поиск, категории и раскрывающиеся ответы.
- Ошибка загрузки FAQ показывается русским текстом с повторной попыткой, а пустой FAQ и пустой результат поиска имеют разные состояния.
- Главная страница показывает FAQ-preview из тех же данных.
- Demo seed создает базовые вопросы для локального запуска.

## API

Публичный API:

- `GET /api/public/content/faq` - активные вопросы для страницы FAQ.
- `GET /api/public/content/faq?home=true` - активные вопросы, разрешенные для главной страницы.

Админский API:

- `GET /api/admin/faq` - список всех вопросов.
- `POST /api/admin/faq` - создать вопрос.
- `PUT /api/admin/faq/{id}` - обновить вопрос.
- `DELETE /api/admin/faq/{id}` - удалить вопрос.

## Проверка

1. Запустить API в режиме `Local`.
2. Проверить, что demo seed создал записи в таблице `FaqEntries`.
3. Открыть `GET /api/public/content/faq` и убедиться, что видны только активные опубликованные вопросы.
4. Войти в админку и открыть раздел `FAQ`.
5. Создать вопрос, изменить категорию/порядок/видимость и проверить публичную страницу FAQ.
