# Управление Telegram-ботом

Раздел админки `Telegram-бот` закрывает roadmap-блок `12.1` и тексты из `12.2`: администратор может менять состояние бота, режим подключения, публичный username, webhook, WebApp URL, admin chat id и основные тексты без ручной правки конфигурации.

## Что настраивается

- Включение или выключение бота.
- Режим `LongPolling` или `Webhook`.
- Public bot username для deep link из личного кабинета.
- Webhook URL, Admin chat id и WebApp URL.
- Bot token и Secret token.
- Welcome text, инструкция подключения, текст поддержки, текст после оплаты, текст продления, текст ошибки оплаты и текст окончания подписки.
- Проверка подключения: админка показывает, готов ли бот к работе, какие обязательные поля еще не заполнены и какие предупреждения стоит учесть.

## Секреты

`Bot token` и `Secret token` остаются write-only. API возвращает только признаки наличия секрета и маску bot token. Пустые поля при сохранении не затирают текущие защищенные значения.

Настройки хранятся в базе через управляемые `SiteContentBlock` записи группы `telegram_bot`, а секреты сохраняются в защищенном виде через `ISecretProtector`.

## Проверка подключения

Кнопка `Проверить подключение` вызывает `POST /api/admin/telegram-bot/settings/test`. Проверка не обращается к Telegram API и не раскрывает токены: она валидирует локальную конфигурацию, чтобы администратор видел готовность до включения live-сценария.

Проверка считает обязательными:

- включенный бот;
- public username без `@`;
- сохраненный Bot token;
- корректный абсолютный `http/https` Webhook URL для режима `Webhook`;
- корректный абсолютный `http/https` WebApp URL, если он заполнен.

Предупреждения не блокируют готовность, но показывают риск: например, отсутствие `Secret token` для Webhook или пустой `Admin chat id`.

## Локальная проверка

1. Запустить backend и админку локально.
2. Войти в админку и открыть `Telegram-бот`.
3. Изменить режим, username, webhook, WebApp URL и тексты сценариев.
4. Ввести test token и secret token, сохранить и проверить, что исходные токены не отображаются в ответе API.
5. Нажать `Проверить подключение` и убедиться, что статус готовности показывает обязательные действия или `Ready`.
6. В личном кабинете создать ссылку привязки Telegram и убедиться, что deep link использует username из админки.
