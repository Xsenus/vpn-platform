# Roadmap: единый сайт, кабинет и админка VPN Platform

Этот документ нужен как рабочий план. По нему отмечаем, что уже сделано, что в работе и что остается довести.

Легенда:

- `[ ]` не начато
- `[~]` в работе
- `[x]` готово

## 0. Цель продукта

Система должна продавать VPN-доступы через публичный сайт, личный кабинет и Telegram-бота, а администратор должен управлять продуктом из админки без правки кода.

Итоговая система должна позволять:

- пользователю выбрать тариф, оплатить и получить VPN-доступ;
- пользователю видеть подписку, платежи, QR-код и ссылку подключения в кабинете;
- администратору менять тарифы, цены, описания, FAQ и контент сайта;
- администратору подключать платежных провайдеров;
- администратору подключать VPN-серверы и 3x-ui панели;
- администратору настраивать сценарий: что происходит после покупки, продления, ошибки оплаты и окончания подписки;
- GitHub Actions должен проверять и деплоить проект на VPS.
