# Управление VPN-серверами

Раздел админки `Серверы` закрывает roadmap-блок `11.1`: серверы можно создавать, редактировать, проверять и ставить в очередь подготовки VPS без ручной правки базы.

## Что настраивается

- Название, Host/DNS, IP-адрес, провайдер, страна, регион и datacenter.
- Емкость, приоритет распределения, поддерживаемые протоколы и теги.
- SSH-пользователь, порт, метод авторизации и проверочный режим.
- Адрес 3x-ui панели, логин панели, inbound id, публичный hostname и порт.

## Секреты

SSH credential и пароль панели остаются write-only. При создании они сохраняются через `ISecretProtector`, а API возвращает только признаки `sshCredentialConfigured` и `panelPasswordConfigured`.

При редактировании пустые поля секретов не затирают уже сохраненные значения. Чтобы заменить секрет, администратор вводит новое значение явно.

## Проверка и подготовка

Кнопка `Проверить` ставит dry-run precheck в очередь подготовки. Кнопка `Подготовить` запускает provisioning-сценарий через backend-контроллер с защитными флагами. Отдельные действия позволяют перевести сервер в обслуживание или открыть/закрыть распределение новых пользователей.

## Локальная проверка

1. Запустить backend и админку локально.
2. Войти в админку и открыть `Серверы`.
3. Создать сервер в проверочном режиме с тестовым host.
4. Нажать `Редактировать`, изменить datacenter, priority, tags и сохранить.
5. Проверить, что список показывает новые значения, а признаки секретов остались без раскрытия самих секретов.
