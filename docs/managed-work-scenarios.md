# Управляемые сценарии работы

Раздел закрывает roadmap-блоки `9.1`, часть `9.2`, `13.1` и `13.2`: сценарии выдачи VPN теперь хранятся в базе и редактируются из админки.

## Возможности

- Администратор создает, редактирует, включает, скрывает и удаляет сценарии работы.
- Сценарий описывает VPN-протокол, правило выбора сервера, правило выбора inbound, режим выдачи, поведение после оплаты, ошибки оплаты, возврата, окончания подписки и продления.
- Для сценария задаются тексты для личного кабинета и Telegram.
- Тариф связывается со сценарием по ключу `provisioningScenario`; в форме тарифа доступен выбор сценария.
- Удаление защищено: сценарий нельзя удалить, если он выбран в тарифе.
- Demo seed создает базовый сценарий `auto`, совместимый с текущими тарифами.

## API

Админский API:

- `GET /api/admin/work-scenarios` - список сценариев.
- `POST /api/admin/work-scenarios` - создать сценарий.
- `PUT /api/admin/work-scenarios/{id}` - обновить сценарий.
- `DELETE /api/admin/work-scenarios/{id}` - удалить сценарий, если он не используется тарифами.

## Проверка

1. Запустить API в режиме `Local`.
2. Проверить, что demo seed создал сценарий `auto` в таблице `WorkScenarios`.
3. Войти в админку и открыть раздел `Сценарии`.
4. Создать сценарий, изменить поведение после оплаты и тексты для кабинета/Telegram.
5. Открыть раздел `Тарифы` и выбрать сценарий в поле `Сценарий выдачи`.
6. Попробовать удалить сценарий, который выбран в тарифе: API должен вернуть ошибку.
