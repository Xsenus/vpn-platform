# Управляемый контент главной страницы

Раздел закрывает roadmap-блоки `8.1`, `8.2`, часть `13.1` и `13.2`: основные тексты главной страницы хранятся в базе, редактируются из админки и загружаются публичным сайтом через API.

## Возможности

- Администратор редактирует hero-тексты, CTA, заголовки блоков и финальный призыв на главной странице.
- Для каждого блока задаются ключ, группа, название поля, описание, тип поля, активность и порядок.
- Публичная главная получает активные блоки из `GET /api/public/content/home`.
- Если API недоступен или блок скрыт, frontend использует fallback-текст из приложения, поэтому главная не ломается.
- Demo seed создает базовый набор блоков для локального запуска.

## API

Публичный API:

- `GET /api/public/content/home` - активные блоки группы `home`.

Админский API:

- `GET /api/admin/site-content?group=home` - список блоков контента.
- `POST /api/admin/site-content` - создать блок.
- `PUT /api/admin/site-content/{id}` - обновить блок.
- `DELETE /api/admin/site-content/{id}` - удалить блок.

## Проверка

1. Запустить API в режиме `Local`.
2. Проверить, что demo seed создал записи в таблице `SiteContentBlocks`.
3. Открыть `GET /api/public/content/home` и убедиться, что возвращаются активные блоки главной.
4. Войти в админку и открыть раздел `Контент сайта`.
5. Изменить `home.hero.title`, сохранить и проверить главную страницу.
