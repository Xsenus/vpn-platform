# Публичный FAQ

Публичная страница `FAQ` закрывает roadmap-блок `3.3`: вопросы загружаются из API, группируются по категориям и отображаются в едином стиле публичного сайта.

## Что реализовано

- FAQ берется из `GET /api/public/content/faq`.
- На главной странице используется preview из `GET /api/public/content/faq?home=true`.
- Категории нормализуются: пустая категория отображается как `Общее`.
- Категории сортируются по русской локали.
- Поиск работает по вопросу, ответу и категории.
- Ответы открываются через раскрывающиеся блоки.
- Для пустого FAQ и пустой поисковой выдачи используются разные сообщения.
- Ошибка загрузки показывается русским текстом и дает кнопку повторной загрузки.

## Проверка

```powershell
cd frontend
npm test
npm run typecheck
npm run build
```

Backend-поведение FAQ проверяется тестами `FaqControllerTests`: public API возвращает только активные вопросы, опубликованные для FAQ, и соблюдает сортировку.
