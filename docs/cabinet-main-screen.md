# Главный экран личного кабинета

Раздел закрывает roadmap-блок `4.2`: пользователь сразу видит состояние VPN-доступа, понимает, что делать дальше, и может перейти к покупке, продлению или подключению.

## Что реализовано

- Над списками добавлена сводка `Текущий VPN-доступ`.
- Сводка выбирает активную или grace-подписку перед старыми записями.
- Показываются тариф, статус, дата окончания, количество дней до окончания и сервер.
- Если есть ключ подключения, показываются ссылка, копирование, QR-код и кнопка продления.
- Если ключ еще не готов, показывается понятное empty state.
- Если подписки нет, показывается CTA `Выбрать тариф`.
- Инструкция подключения отображается прямо на первом экране кабинета.
- Логика выбора текущей подписки и связанного доступа вынесена в тестируемый helper.
- Для старых локальных SQLite-БД добавлен repair недостающего поля `PaymentProviderAccounts.WebhookUrl`, чтобы кабинет не падал при загрузке способов оплаты.

## Проверка

```powershell
cd frontend
npm test
npm run typecheck
npm run build
```

Для ручной проверки:

1. Запустить локальную среду без Docker.
2. Открыть кабинет.
3. Проверить состояние без подписок: должна быть кнопка перехода к тарифам.
4. Проверить пользователя с активной подпиской: видны статус, дата окончания, ссылка подключения, QR-код и продление.
