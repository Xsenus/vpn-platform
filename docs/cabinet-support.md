# Поддержка в личном кабинете

## Что реализовано

Блок `4.4 Поддержка` закрывает сценарий обращения в поддержку без Telegram. Пользователь может:

- создать обращение из личного кабинета;
- привязать обращение к своему заказу или подписке;
- видеть список своих обращений;
- открыть переписку по обращению;
- отправить новое сообщение в существующую переписку;
- закрыть обращение или переоткрыть его, если вопрос снова актуален.

## API

Добавлены пользовательские endpoint’ы в `api/me`:

- `GET /api/me/support/conversations`;
- `POST /api/me/support/conversations`;
- `GET /api/me/support/conversations/{id}/messages`;
- `POST /api/me/support/conversations/{id}/reply`;
- `PATCH /api/me/support/conversations/{id}/status`.

API проверяет, что заказ или подписка, выбранные в форме, принадлежат текущему пользователю. Внутренние заметки администратора не отдаются пользователю в переписке.

## Проверки

Добавлены backend unit-тесты на создание обращения, привязку к заказу/подписке, скрытие внутренних заметок и запрет привязки чужого заказа. Добавлены frontend-тесты API-клиента и helper-логики поддержки.
