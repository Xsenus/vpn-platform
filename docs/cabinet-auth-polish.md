# Авторизация личного кабинета

Раздел закрывает roadmap-блок `4.1`: вход, регистрация и восстановление пароля приведены к единому поведению на публичной странице `/account` и в отдельном приложении кабинета.

## Что реализовано

- Вход и регистрация используют единый segmented control с доступной навигацией с клавиатуры.
- Формы проверяют email и минимальную длину пароля до отправки запроса.
- Ошибки backend-кодов авторизации переводятся на русский язык.
- Сброс пароля использует отдельную проверку email, кода сброса и нового пароля.
- Сообщение backend о поставленной в очередь инструкции сброса переводится на русский язык.
- Кнопки отправки блокируются во время загрузки и при невалидных данных.
- Для пользователя отображаются loading, success и error состояния.

## Проверка

```powershell
cd frontend
npm test
npm run typecheck
npm run build
```

Для проверки на локальной SQLite-БД запустите проект без Docker:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1
```

Проверяемые сценарии:

- открыть публичную страницу `/account`;
- попробовать отправить форму с неверным email или коротким паролем;
- зарегистрировать нового пользователя;
- войти существующим пользователем;
- запросить код сброса пароля в Local-режиме;
- сохранить новый пароль и войти с ним.
